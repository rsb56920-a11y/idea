## 1. どんなゲームか

**一言で言うと：「デフォルメロボで大穴に潜って、レアパーツを持ち帰るか、欲張って全部失うか」**

- ジャンル：3D風の奥スクロール・シューティング × ローグライト（ハクスラ要素あり）
- 参考にした雰囲気：PS1『雷弩機兵ガイブレイブII』（デフォルメロボ、パイロットとの掛け合い、奥スクロール）。ただし名前・キャラ・デザインはすべてオリジナル。原作の固有名詞や見た目は使わないこと
- 目標：Steam で売れて、配信者が遊びたくなるゲーム
- 1回の出撃は15〜20分くらいで、「もう1回」と言いたくなる長さ

### 世界観
- 十年前に突然開いた巨大な縦穴「大穴（ホール）」
- 奥に潜るほど、古代の機械パーツが眠っている
- 「ダイバー」はロボで潜り、パーツを持ち帰って暮らしている
- 舞台は大穴の縁にある格納庫。オペレーターの「ノア」がナビ役

### 配信映えのための3本柱（ここはブレさせない）
1. **帰るか進むかの賭け**：深度クリアごとに「帰還」か「もっと奥へ」を選ぶ。撃墜されたら、その出撃で拾ったパーツは全部失う
2. **パーツで見た目も弾も変わる**：付けたパーツがロボのシルエットにそのまま出る。強化を重ねると、画面が弾で埋まるぶっ壊れ機体になる
3. **推せるパイロット**：4人それぞれ性能と性格が違う。帰還するたびに絆が深まり、短いエピソードが解放される

## 2. 今の状態

- `index.html` 1ファイルで動くブラウザ試作（HTML + CSS + 素のJavaScript、約1,300行、外部ライブラリなし）
- ブラウザで開くだけで遊べる。スマホ（タッチ）とPC（矢印キー / WASD）の両方に対応
- フォントだけ Google Fonts（Dela Gothic One / Zen Kaku Gothic New）を読み込んでいる
- セーブは `localStorage`（キー：`gear-diver-save-v1`）
- 絵はすべて Canvas 2D で描いた仮のもの。音は Web Audio でその場で合成している（音声ファイルなし）

### 前の試作との関係
- 先に「鉄騎ブレイズ」という試作があった（ストーリー6話制、撃墜しても持ち帰れる仕様）
- 「緊張感がない」「ストーリー性・装備・弾が単調」という理由で、今の「ギアダイバー」に作り直した
- 鉄騎ブレイズのコードは使わない。参考にするなら今の `index.html` だけでいい

## 3. ゲームの流れ

```
格納庫（パイロット選択・パーツ装備）
  → 出撃（深度1）
  → 深度クリア → ゲート画面：「帰還する」 or 「深度N+1へ潜る」
       ├ 帰還 → カーゴを全部持ち帰る・絆+1（深度6以上なら+2）→ 格納庫
       └ 潜る → 強化カードを3枚から1枚選ぶ → 次の深度へ
  → 撃墜 → カーゴ全損（クレジットは2割だけ戻る）→ 格納庫
```

- 3深度ごとにボス（深度3, 6, 9…）
- 3深度ごとに「層」が変わり、景色の色が変わる：入口層 → 結晶洞 → 溶鉄層 → 深淵
- 深度クリアごとにHPが15%回復
- 一時停止から途中で戻ると、撃墜と同じ扱い（カーゴを失う）

### 操作
- 左右ドラッグ（または ←→ / AD）：横移動
- 上下ドラッグ（または ↑↓ / WS）：前後移動（前に出るほど当てやすいが避けにくい）
- 射撃は自動。P / Esc で一時停止
- ロボは地面を走る。上下（高さ）の移動はなし。これはユーザーの希望（「横と前後のイメージ」）

## 4. システムの中身

### パーツ（装備スロットは3つ：腕・肩・脚）
| 部位 | 種類 |
|---|---|
| 腕部武装（メイン武器） | パルスライフル、ガトリング、ブラストショット（散弾）、バスターキャノン（爆発弾）、ドリル（近接・貫通）、フレイム（火炎・延焼） |
| 肩部兵装（サブ） | ミサイルポッド（追尾）、レーザーキャノン（直線ビーム）、ガンビット（随伴機）、グレネード砲（山なり榴弾）、シールドユニット（バリア） |
| 脚部 | 二脚、ホバー（速い）、キャタピラ（硬い・遅い）、ジェット脚（速い・回収範囲広い） |

- レア度：N / R / SR / SSR / LR（出現率の重み 60 / 27 / 10 / 2.6 / 0.4）。深いほど・レア率が高いほど上位が出やすい
- R以上はランダムな追加効果（攻撃力、連射、会心率、最大HP、機動力、回収範囲、レア率）が付く
- 属性：炎・氷・雷。**同じ属性のパーツを2つそろえるとシナジー発動**（炎＝焼夷、氷＝凍結、雷＝連鎖雷撃）。3つでLv2
- LR専用効果：腕＝弾+1列、肩＝発射数+2、脚＝撃墜されても1回だけ再起動
- 付けたパーツの形と色（レア度の色）がロボの見た目に出る（`drawMech()`）

### 強化カード（その出撃の間だけ有効・重ねがけ可）
マルチバレル（弾+1列）、高速給弾、高圧弾芯、徹甲弾、分裂弾、誘爆、焼夷弾、雷撃回路、兵装増設、随伴ドローン、周回ブレード（敵弾も消す）、装甲パッチ、探知ソナー、欲張りビーコン（レア率↑・被ダメ↑のリスク札）

### パイロット
| 名前 | タイプ | 特性 |
|---|---|---|
| アカネ | 突撃型 | 深度が1上がるごとに威力+8%。深層で消えた兄を探している |
| シズク | 慎重型 | 撃墜されても一番レアなパーツを1つ持ち帰る。帰還時のCR+20%。元救助隊 |
| ルカ | 強欲型 | レア率+30%、最大HP-20%。自分のパーツ屋を開くのが夢 |
| テツ | 鉄壁型 | 最大HP+40%、被ダメ-10%、機動力-10%。古参ダイバー |

- 絆は0〜5。絆1・3・5でエピソード（1人3話、会話シーン）が解放
- 出撃中は状況に応じてパイロットが無線でしゃべる（出撃・潜行・レア取得・HP低下・ボス・帰還・撃墜）

### 敵とボス
- 雑魚：ドローン（編隊）、ダイバー（突っ込んでくる）、砲台（3WAY弾）、強敵エリート（扇状弾・連射・地面レーザー）
- ボス：掘削母艦ガルム / 結晶獣クリスタロス / 溶鉄砲塔ヴォルカ / 深淵王ネメシス（深度12以降は周回してHP増）
- ボスの攻撃パターン：扇状弾（隙間あり）、連射、雑魚召喚、地面が赤く光ってからのレーザー、らせん弾

### 気持ちよさの演出
- ヒットストップ（スロー）：ボス撃破、エリート撃破、SSR/LR取得時
- SR以上のドロップは光の柱、SSR/LRは画面にバナー
- 画面揺れ、ダメージ数字、会心は黄色
- 効果音（武器ごとに音が違う）とBGM（深く潜るほど楽器が増えて激しくなる）

## 5. コードの地図（`index.html`）

すべて1つの即時関数の中にある。主な場所：

| 何 | どこ |
|---|---|
| データ定義（レア度、パーツ、カード、層、ボス、パイロット、会話） | `RAR` `BASES` `CARDS` `LAYERS` `BOSSES` `PILOTS` `INTRO` |
| パーツ生成・評価・装備ステータス計算 | `makePart()` `itemScore()` `calcBase()` |
| 出撃中の最終ステータス（カード込み） | `computeF()` → `G.F` |
| 音 | `audioInit()` `sfx()` `bgmStart()` `bgmTick()` |
| 3D風の座標変換 | `P(x,y,z)`（z＝奥行き、カメラは機体の後ろ上） |
| 背景・ロボ描画 | `drawBackdrop()` `drawMech()` `drawEnemy()` `drawWorld()` |
| 出撃の流れ | `startRun()` `startZone()` `zoneClear()` `cardSelect()` `endRun()` |
| 敵の出現・挙動・ボス攻撃 | `spawnTick()` `updateEnemy()` `bossAttack()` |
| 攻撃・命中処理 | `playerShoot()` `shoulderShot()` `droneShot()` `onHit()` `kill()` `dropItem()` |
| メインループ | `update()` `frame()` |
| 会話シーン・無線 | `talk()` `comms()` |
| 格納庫UI | `openHangar()` `renderHangar()` `openDetail()` |
| 差し替え画像（一覧・読み込み・位置調整の表） | スクリプト先頭の `ASSETS` `FACE_CROP` `MECH_ART` `MECH_OFS` `ENEMY_ART`、`preloadArt()` `sprite()` `faceCss()` `standArt()` |

座標のメモ：横 x は -2.3〜2.3、機体の奥行き z は 1.5〜3.1、敵は z=20〜26 から出てくる。

## 6. 次にやること（優先順）

### A. 試作のまま、遊びの芯を確かめる（今ここ）
1. 実際に遊んでもらって、「帰るか進むか」で本当に迷うかを確認する。迷わないなら、深度ごとのレア率の伸びと敵の強さのバランスを調整する
2. 強化カードを重ねたときの「ぶっ壊れ感」をもっと派手にする（弾数・エフェクト・画面の埋まり方）
3. パーツの組み合わせボーナスを増やす（例：炎の腕＋拡散系の肩で、炎がばらまかれる）
4. 10〜15秒のプレイ動画を撮って X に出し、反応を見る

### B. 見た目を今風にする
- ユーザーは **PixAI** でキャラ画像を作る予定。**画像差し替えのしくみは実装済み**（`画像差し替え指示書.md` 参照）。`assets/` に PNG を置くと、立ち絵・顔アイコン・ロボのパーツ・敵・背景がその部分だけ差し替わる。画像がない部分は今までのコード描画のまま
- ロボはデフォルメ（魔神英雄伝ワタルのような頭身感）。将来的にはアニメ調の3D（セルルック）が理想

### C. 製品版に向けて
- Steam で出すなら、Godot か Unity で作り直すのが現実的（このPCには Unity の痕跡あり。どちらにするかはユーザーに確認すること）
- キーボード・コントローラー対応、セーブの堅牢化、解像度対応
- 体験版 → Steam Next Fest → ウィッシュリスト集め、の流れを想定
- Steam の登録料は1本100ドル（売上1,000ドル超えで戻る）。体験版に追加料金はない
- 配信OKのガイドラインを明記する
- 余裕があれば2〜4人の協力プレイ（仲間を回収しに行ける仕組み）
