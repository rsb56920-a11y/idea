# 画像差し替え指示書（ギアダイバー）

キャラ・ロボ・敵・背景を、PixAI などで作った画像に差し替えるための指示書です。

- **前半（第1〜4章）**：ユーザー向け。どんな画像を、どのサイズ・どの名前で作ればいいか
- **後半（第5章）**：Claude Code 向け。画像を読み込んでゲームに組み込む方法（実装済み。調整のしかたは第6章）

---

## 1. 全体のルール

### 作る順番（おすすめ）
1. **パイロット4人＋ノアの立ち絵**：いちばん効果が大きく、作りやすい
2. **背景4枚**（層ごと）
3. **敵とボス**
4. **ロボのパーツ**：いちばん難しい（理由は第3章）
5. **Steam用のキービジュアル**：絵柄が固まってから

全部そろわなくても大丈夫。**画像がない部分は今の仮の絵のまま動く**。1枚ずつ入れて確認できる。

### ファイルの共通ルール
- 形式は **PNG**
- キャラ・ロボ・敵は **背景を透明** にする
  - PixAI で透明背景が出せないときは、白か単色の背景で作って、あとで背景を消す（このPCに入っている rembg や、背景削除ツールを使う）
- ファイル名は **半角英数字と _（アンダーバー）だけ**。日本語や空白は使わない
- 全部 `assets` フォルダの中に、下の表のとおりに入れる

```
gear-diver/
├ index.html
├ CLAUDE.md
├ 画像差し替え指示書.md
└ assets/
   ├ pilots/      … パイロットとノアの立ち絵
   ├ mech/        … ロボのパーツ
   ├ enemies/     … 雑魚敵とボス
   ├ bg/          … 背景
   └ store/       … Steam用（あとで）
```

### 絵柄をそろえるコツ
- 全キャラで **同じモデル・同じLoRA・同じ基本プロンプト** を使う
- 基本プロンプトをメモしておいて、キャラごとの部分だけ入れ替える
- 気に入った1枚ができたら、その設定（シード値など）を記録しておく

## 2. パイロットとノア（`assets/pilots/`）

### 必要な画像
1人につき **立ち絵4表情**。全員 **20代以上の大人** として描く。

| 表情 | ファイル名の末尾 | 使う場面 |
|---|---|---|
| ふつう | `_normal` | 基本 |
| 笑顔 | `_smile` | 帰還成功、レア取得 |
| 真剣・怒り | `_serious` | ボス、深く潜るとき |
| 悲しみ・焦り | `_sad` | 撃墜、HP低下 |

- サイズ：**縦 1536 × 横 1024**（縦長）
- 構図：**ひざ上〜腰上**、正面かやや斜め、頭の上に少し余白
- 4表情とも **同じポーズ・同じ位置・同じサイズ**（表情だけ変える）。差し替えたときに体がズレないように
- 顔アイコンは立ち絵から自動で切り抜くので、別に作らなくていい
- `_normal` だけ先に入れてもOK。ほかの表情がないときは `_normal` が使われる

### ファイル名
```
akane_normal.png   akane_smile.png   akane_serious.png   akane_sad.png
shizuku_normal.png …
ruka_normal.png …
tetsu_normal.png …
noa_normal.png …
```

### キャラの見た目（案）
ゲーム内の色（名前の色）に合わせてある。好みで変えてOK。変えたら第5章の色も合わせて直してもらう。

| キャラ | イメージカラー | 見た目の案 |
|---|---|---|
| アカネ（突撃型） | 赤オレンジ `#ff6a3d` | 赤みがかった短髪、ゴーグルを頭にのせている、赤と黒のパイロットスーツ、勝ち気な表情 |
| シズク（慎重型） | 水色 `#5ad1ff` | 水色のロングヘアをポニーテール、落ち着いた目、白と青のスーツに救助隊っぽい反射ライン |
| ルカ（強欲型） | 金 `#ffc23d` | 金髪ツインテール、明るい笑顔、金色の差し色、腰に工具ベルトとがま口ポーチ |
| テツ（鉄壁型） | 緑 `#8fe388` | 50代の男性、白髪まじりの短髪とあごひげ、使い込んだ緑のジャケット、頬に古傷、バンダナ |
| ノア（オペレーター） | 薄紫 `#c9a8ff` | 薄紫のボブ、ヘッドセット、メガネ、制服の上にパーカー |

### PixAI用プロンプトの例
基本部分（全員共通）：
```
masterpiece, best quality, anime style, cel shading, upper body to thigh,
standing, facing viewer, simple white background, pilot suit, mecha pilot,
adult, sci-fi
```
キャラごとに足す部分（アカネの例）：
```
1girl, short red-orange hair, goggles on head, red and black pilot suit,
confident smile, determined eyes
```
表情を変えるときは最後の表情の部分だけ入れ替える：
- normal：`neutral expression`
- smile：`big smile, happy`
- serious：`serious face, frowning`
- sad：`sad expression, teary eyes`

## 3. ロボ（`assets/mech/`）

### なぜ難しいか
このゲームのロボは、**腕・肩・脚のパーツを付け替えると見た目が変わる**。
だから、パーツを1つずつ別々の画像で用意して、ゲームの中で組み立てる必要がある。
AIで「同じ絵柄・同じ大きさ・同じ角度」のパーツをそろえるのは、キャラよりかなり難しい。

### おすすめの進め方（3段階）
1. **まずは今の描画のまま**。キャラ・背景・敵を先に差し替える
2. 次に **胴体（本体）だけ** 画像にする。パーツは今の描画のまま重ねる
3. 最後に、パーツも画像にそろえる。どうしてもそろわない場合は、ロボだけ「イラストを元にした2D絵を自分で清書する」か「3Dモデルを使う」を検討する

### 向きと構図
- ゲーム中は **機体の真後ろ・少し上から** 見ている（背中が見える）
- 格納庫の表示も同じ後ろ向き
- 頭身は **2〜2.5頭身のデフォルメ**（ずんぐり、かわいい系）
- 白をベースに、差し色（パイロットの色）が入る場所を作っておく

### パーツの一覧とファイル名
すべて **縦 512 × 横 512**、透明背景、**同じ縮尺**。キャンバスの中心＝胴体の中心、として描く。

| 部位 | ファイル名 |
|---|---|
| 胴体（頭込み） | `body.png` |
| 腕部武装（右腕に付く） | `arm_rifle.png` `arm_gatling.png` `arm_shotgun.png` `arm_cannon.png` `arm_drill.png` `arm_flame.png` |
| 肩部兵装（左肩に付く） | `sho_missile.png` `sho_laser.png` `sho_bit.png` `sho_mortar.png` `sho_shield.png` |
| 脚部 | `leg_biped.png` `leg_hover.png` `leg_tread.png` `leg_jet.png` |

- 各パーツは、512×512 のキャンバスの中で「胴体に付いたときの位置」に描く（全部重ねるとロボが完成する状態）。これがいちばんズレない
- 位置がズレたときは、第6章の「位置調整の表」で数字を変えれば直せる
- レア度の色（N白・R青・SR紫・SSR金・LR赤）は、ゲーム側でパーツのまわりを光らせて表現する。画像に色を塗り分けなくていい

### PixAI用プロンプトの例（パーツ単体）
```
masterpiece, best quality, anime style, cel shading, chibi mecha part,
back view, white armor with orange accents, isolated, simple white background,
(パーツの説明 例: gatling gun arm, multiple barrels)
```

## 4. 敵・背景・Steam用

### 敵とボス（`assets/enemies/`）
敵は **こちらに向かってくる正面向き**。透明背景。

| ファイル名 | 何か | サイズ |
|---|---|---|
| `drone.png` | 編隊で飛んでくる小型機 | 256×256 |
| `diver.png` | 突っ込んでくる三角形の機体 | 256×256 |
| `turret.png` | 3つの砲口がある浮遊砲台 | 256×256 |
| `elite.png` | 脚が4本ある大型機 | 512×512 |
| `boss_garm.png` | 掘削母艦ガルム（オレンジ、六角形の母艦） | 1024×1024 |
| `boss_crystal.png` | 結晶獣クリスタロス（青緑の結晶の球体） | 1024×1024 |
| `boss_volca.png` | 溶鉄砲塔ヴォルカ（双頭の砲塔、溶けた鉄） | 1024×1024 |
| `boss_nemesis.png` | 深淵王ネメシス（紫、王冠をかぶった機械の王） | 1024×1024 |

敵はダメージを受けると白く光る。これはゲーム側でやるので、白い版は作らなくていい。

### 背景（`assets/bg/`）
画面の **上半分（空〜地平線）** に使う。地面のグリッドはゲーム側で描くので、地面は描かなくていい。

| ファイル名 | 層 | イメージ |
|---|---|---|
| `layer1.png` | 入口層（格納庫の画面にも使う） | 夕焼け、遠くに大穴のふち、崖のシルエット |
| `layer2.png` | 結晶洞 | 青緑の結晶が光る洞窟の天井と壁 |
| `layer3.png` | 溶鉄層 | 赤くどろどろの溶けた鉄、熱気 |
| `layer4.png` | 深淵 | 紫の闇、古代の巨大機械の影 |

- サイズ：**横 1920 × 縦 1080**
- 下の端（地平線）は暗めにしておくと、地面とつながってきれい
- 画面の形によって上や左右が少し切れるので、大事なものは真ん中寄り・下寄りに

### Steam用（`assets/store/`）あとでOK
ストアページ用の画像。サイズは提出前に Steamworks の公式ドキュメントで必ず確認すること。目安：
- ヘッダー：920×430
- メインカプセル：1232×706
- 縦長カプセル：748×896
- ライブラリ用：600×900
- ライブラリのヒーロー画像：3840×1240

## 5. Claude Code への実装指示（実装済み）

以下は `index.html` に実装済み。ユーザーに説明するときは、専門用語を避けること。

### 5-1. 読み込みのしくみ
- `assets/` 以下の画像を、起動時に先読みする（一覧はスクリプト先頭の `ASSETS`）
- 画像が見つからない・読み込みに失敗したときは、今の Canvas 描画をそのまま使う
- 格納庫のいちばん下に「差し替え画像 ○ / 48 枚 読み込み済み」を表示。タップでどれが入っているか一覧が出る

### 5-2. パイロット
- 会話シーン（`talk()`）：会話ウィンドウの上に立ち絵を表示。ノアは右、パイロットは左、1人だけなら真ん中。話していない方は暗くする
- 会話データの3つ目に表情を指定できる（`['アカネ','セリフ','smile']`、省略時は `normal`）。既存の会話（`PILOTS[].eps` と `INTRO`）には表情を付け済み
- 顔アイコン（格納庫のパイロット選択、会話ウィンドウの丸、無線、帰還／撃墜画面）は立ち絵の顔あたりを丸く切り抜いて使う。位置は `FACE_CROP`
- 出撃中の無線（`comms()`）にも顔アイコン。レア取得→smile、HP低下・撃墜→sad、ボス・潜行→serious（`BARK_EX`）
- 立ち絵がないキャラは、今の丸い頭文字アイコンのまま

### 5-3. ロボ
- `drawMech()`：画像があるパーツは画像、ないパーツは今までのコード描画（混ぜて表示できる）
- 重ねる順番（奥→手前）：脚の噴射 → 脚 → 胴体 → 肩 → 腕 → 発射の光
- 位置調整は `index.html` 内の表 `MECH_ART` と `MECH_OFS`（ブラウザでファイルを直接開くと別ファイルの .json は読めないため、表は index.html の中に置いた）
- レア度の色は、パーツ画像のまわりを光らせて表現
- 噴射の炎、発射の光、シールドの円、ドローン、周回ブレードは、今までどおりコードで描く

### 5-4. 敵・背景
- `drawEnemy()`：画像があれば、敵の大きさ（`e.r`）×`ENEMY_ART` の倍率で描く。被弾時は白く光らせた画像を重ねる。ボスは体力半分以下で赤く脈打つ光を重ねる
- ボスは `BOSSES[].img` で画像を指定
- 燃えている・凍っている表示は画像の上に重ねる
- `drawBackdrop()`：層の背景画像（`LAYERS[].img`）があれば地平線から上に描き、横移動に合わせて少しずらす。星と光は上に重ねる

## 6. あとから自分で調整するとき

`index.html` をメモ帳などで開き、上のほうにある表の数字を変えて保存 → ブラウザを再読み込み。

| 直したいこと | 表の名前 | 変える数字 |
|---|---|---|
| 顔アイコンの切り抜き位置 | `FACE_CROP` | `x`（左右 0〜1）、`y`（上下 0〜1）、`size`（小さくするほどアップ） |
| ロボ全体の画像の位置・大きさ | `MECH_ART` | `cx`・`cy`（ずらす量）、`size`（大きさ） |
| ロボのパーツ1つの位置・大きさ | `MECH_OFS` | `x`（右へ）、`y`（下へ）、`s`（倍率）。腕の `fx`・`fy` は発射の光の位置 |
| 敵の画像の大きさ | `ENEMY_ART` | `size`（大きくすると敵の絵が大きくなる。当たり判定は変わらない） |
