# ZETA風 AIキャラクターチャット

ZETA のような「AIキャラクターと会話する」Webアプリです。Claude API を使ってキャラクターがロールプレイで返信します。

## 機能

- **ホーム**: おすすめキャラ一覧、ジャンル絞り込み、検索、最近話したキャラ
- **チャット**: ストリーミング返信、`*行動描写*` の表示、再生成、コピー、会話リセット
- **キャラ作成**: アイコン(絵文字/画像)、名前、紹介、性格・設定、世界観、最初のセリフ、ジャンル
- **マイページ**: ペルソナ設定(キャラから呼ばれる名前・プロフィール)、作ったキャラの管理
- データ(キャラ・会話履歴)はブラウザの localStorage に保存

## 起動方法

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 未設定ならデモモード(定型文で返信)
npm start
# → http://localhost:3000
```

| 環境変数 | 説明 | 既定値 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API キー | なし(デモモード) |
| `CLAUDE_MODEL` | 使用モデル | `claude-opus-5` |
| `PORT` | ポート | `3000` |

APIキーはサーバー側だけで使われ、ブラウザには送られません。
返信が拒否された場合は、API のサーバー側フォールバック(`fallbacks: "default"`)で別モデルが自動的に応答します。
