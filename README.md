# 売れる商品フォルダー

AIを使った「売れやすさ重視」のWebアプリと、その売り方をまとめたフォルダーです。

| フォルダー | 中身 | 状態 |
|---|---|---|
| [`占い_星詠みルナ/`](占い_星詠みルナ/) | AI占い・診断アプリ(今日の運勢/推し相性/タロット/相性/前世) | 動作OK・決済はStripe対応 |
| [`性格診断_ココロタイプ/`](性格診断_ココロタイプ/) | 16タイプ性格診断(無料診断はAI代ゼロ、有料レポートだけAI) | 動作OK・決済はStripe対応 |
| [`ボイスチェンジャー_コエカワ/`](ボイスチェンジャー_コエカワ/) | **コエカワ**:自然な女声・美少年・両声類ボイスに変えるボイスチェンジャー。`コエカワ.html` をダブルクリックで動く | 動作OK |
| [`夜華カナタ_配信セット/`](夜華カナタ_配信セット/) | 夜華カナタのOBS配信セット(動く待機画面・口パクPNGTuber・Twitch通知・ミニマップ隠し・操作パネル・コエカワ入り)。`はじめにお読みください.html` から | 動作OK・Pythonなし |
| [`画像から動画/`](画像から動画/) | 写真からゆっくり動く縦動画・スライドショーを作る(MP4書き出し) | 動作OK |
| [`ZETA風チャット/`](ZETA風チャット/) | AIキャラクターと会話するアプリ | 動作OK・課金なし |
| [`販売方法/`](販売方法/) | 値段・集客・決済・公開・法律まわりの手順 | まず `00_はじめに読む.md` |

## 動かし方(共通)

1. [Node.js](https://nodejs.org/ja)(LTS版)をインストール
2. 動かしたいフォルダーでコマンドを実行
   ```bash
   cd 占い_星詠みルナ
   npm install
   npm start
   ```
3. ブラウザで http://localhost:3000 を開く

APIキー(`ANTHROPIC_API_KEY`)を設定しない場合は、AIを使わない「デモモード」で動きます。
Windows(PowerShell)でキーを設定する場合: `$env:ANTHROPIC_API_KEY="sk-ant-..."` のあとに `npm start`
