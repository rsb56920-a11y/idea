# 星詠みルナ — AI占い・診断アプリ

AI占い師「ルナ」が鑑定する、スマホ向けの占いWebアプリです。

## メニュー

| メニュー | 入力 | 結果 |
|---|---|---|
| 今日の運勢 | 名前・生年月日 | 総合運スコア、恋愛/仕事/金運/対人運 |
| タロット占い | 名前・悩み → カードを3枚選ぶ | 過去/現在/未来/相談への答え |
| 相性診断 | ふたりの名前・誕生日・関係 | 相性度、うまくいくポイントなど |
| 前世診断 | 名前・生年月日 | 「あなたの前世は〇〇」、才能・課題など |

## 売るための仕組み

- **無料部分:** 見出し・スコア・要約(続きが気になるところで止める)・ラッキーアイテム
- **有料部分(詳細鑑定 ¥300):** 4項目の詳しい鑑定。ぼかし表示+購入ボタン
- **拡散:** 𝕏 投稿ボタン、結果をSNS用画像(1080×1350)で保存・共有
- **リピート:** 「今日の運勢」は毎日内容が変わる。名前・誕生日を記憶して2回目から入力を省略

> ⚠️ 決済は**デモ**です(ボタンを押すと無料で開きます)。
> 本番で売るには Stripe Checkout などの決済をつなぎ、有料部分を**サーバー側で**購入確認後に返すよう変更が必要です
> (現状は鑑定全文をブラウザに送り、画面でぼかしているだけです)。

## 起動方法

```bash
cd fortune
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 未設定ならデモモード
npm start   # → http://localhost:3000
```

| 環境変数 | 説明 | 既定値 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API キー | なし(デモモード) |
| `CLAUDE_MODEL` | 使用モデル | `claude-opus-5` |
| `RATE_LIMIT_PER_HOUR` | 1IPあたり1時間の鑑定回数上限(API料金の使いすぎ防止) | `20` |
| `PORT` | ポート | `3000` |
