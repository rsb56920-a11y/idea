セフィロスコード用 追加アプリ
==========================

入っているもの
- ZETA風チャット.html … キャラクターチャット。セフィロスコードのローカルAIにつないで使う
- 画像から動画.html   … 写真+「お願い」で動画に。なぞった所だけ動かせる
- index.html          … 上の2つを開くメニュー

入れ方(かんたん)
1. 「セフィロスコードに入れる.bat」をダブルクリック
   → F:\LocalCloudCode\web\extras に入ります
2. セフィロスコードを起動して、アドレスの最後に /extras/ をつけて開く
   (または extras フォルダの index.html をダブルクリック)

チャットの最初の設定
- 「マイページ」→「ローカルAIの設定」で、つなぎ先(Ollama / LM Studio など)を選んで
  「モデル一覧を読み込む」→「保存」
- Ollama がブラウザから「つながらない」ときは、環境変数 OLLAMA_ORIGINS に * を設定して Ollama を起動し直す

イージスにも入れたいとき
- install.ps1 をメモ帳で開き、「# $Targets += ...」の行の # を消して、イージスの web フォルダの場所に書き換えて保存
- それから「セフィロスコードに入れる.bat」をダブルクリック

もっときれいに組み込みたいとき(メニューに出すなど)
- 「セフィロスコードをまとめる.bat」をダブルクリックすると、デスクトップに
  「セフィロスコード_送る用.zip」ができるので、それをチャットに送ってください
  (AIモデルなどの大きいファイルや .env は入りません)

※ 既存の機能には手を付けていません(extras フォルダを足すだけです)
