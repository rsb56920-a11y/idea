# 引き継ぎ: セフィロスコードに「キャラクターチャット」と「画像から動画」を組み込む

## やってほしいこと
`F:\LocalCloudCode`(セフィロスコード。`launch_web.ps1` で起動し、`web\` の画面をブラウザで開くチャットUI)に、
このフォルダの2つのアプリを組み込み、**セフィロスコードの画面(メニューやボタン)から開けるようにする**。

1. このフォルダの `index.html`・`ZETA風チャット.html`・`画像から動画.html` を `F:\LocalCloudCode\web\extras\` にコピーする
   (`セフィロスコードに入れる.bat` をダブルクリックしてもよい)
2. `F:\LocalCloudCode\web\` の画面のファイルを読み、メニューかヘッダーに「追加アプリ」へのリンク(`extras/index.html`)を足す
3. `launch_web.ps1` が使うローカルサーバーで `/extras/` が開けるか確かめる(開けなければ、静的ファイルの配信先に extras を足す)
4. キャラクターチャットを、セフィロスコードが使っているローカルAIにつなぐ
   - `ZETA風チャット.html` は OpenAI 互換の `{URL}/chat/completions`(ストリーミング)と `{URL}/models` を使う
   - 初期値は Ollama(`http://localhost:11434/v1`)。セフィロスコードの設定ファイルから実際のURL・モデル名を読み、
     チャットの「マイページ → ローカルAIの設定」の初期値に合わせる(`store.ai` / localStorage `zeta-like-chat:v1`)
   - Ollama でブラウザから「つながらない」場合は、環境変数 `OLLAMA_ORIGINS=*` で起動し直す
5. イージス(別のアプリ)にも同じように入れる場合は、`install.ps1` の `$Targets` にイージスの web フォルダを足す

## 守ること
- **既存の機能には手を付けない**(消さない・止めない・制限をかけない)。共通のファイルを触るときは「足すだけ」にして、変えた所を報告する
- 18歳以上向け(性的な内容)の機能・設定・プリセットは追加しない
- AIモデル(.gguf など)や `.env` などのキー・パスワードは動かさない・表示しない

## 中身
| ファイル | 内容 |
|---|---|
| `ZETA風チャット.html` | ZETA風キャラクターチャット(1ファイル)。キャラ作成・会話・保存。ローカルAIに直接つなぐ |
| `画像から動画.html` | 写真+「お願い」の文章で動画に。舞うもの(桜・雪…)・色・光・カメラ。なぞった所だけ動かす(WebGL) |
| `index.html` | 上の2つを開くメニュー |
| `セフィロスコードに入れる.bat` / `install.ps1` | `F:\LocalCloudCode\web\extras\` にコピー |
| `セフィロスコードをまとめる.bat` / `collect.ps1` | セフィロスコードの小さいファイルだけを zip にまとめる(大きいモデルや .env は入れない) |
| `src/zeta-app.js` | チャットの元のコード(`ZETA風チャット/public/app.js` をローカルAI用に改造したもの) |

## 画像から動画の残りの課題(手があけば)
- 「水面がゆれる」と書くと「風でゆれる」(ゆれ)も反応してしまう → `wish.js` のゆれの規則を「水面」以外のときだけにする
- 水の自動さがし(`motion.js` の `autoMask`)が効かない写真がある
- 空を動かすと周りの山も少し動く(マスクのぼかしが広い)
- 予定していた「立体(2.5D)」は未着手
