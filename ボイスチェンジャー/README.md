# ナチュラルボイスチェンジャー

地声(例:41歳男性・約100Hz)から、女の子・お姉さん・美少年・両声類(中性)・ショタ・低音イケボの声に変えるボイスチェンジャーです。
ブラウザだけで動き、**音声はどこにも送信しません**。

## 自然に聞こえる理由

| よくある安いボイスチェンジャー | これ |
|---|---|
| 声の高さだけ上げる → 口や喉まで小さくなったような「ヘリウム声」「早回し声」 | 声の高さ(ピッチ)と響き(フォルマント)を**別々に**動かす |
| 全員同じ設定 | 最初に**あなたの声の高さを測り**、目標の高さ(女の子なら約250Hz)に自動で合わせる |
| 倍音を1本ずつばらばらにずらす → 濁る・響く | 倍音の山ごとにまとめてずらし、位相の関係を保つ(Laroche-Dolson 方式)→ 濁りにくい |
| 高くすると声が小さくなる | 元の声と同じ音量に自動でそろえる |

テスト(合成した100Hzの男声を「女の子」に変換)では、声の高さが約2.45倍(→約250Hz)になり、抑揚もそのまま残ることを確認しています。

## 使い方

```bash
cd ボイスチェンジャー
npm start          # 追加のインストールは不要
# → Chrome か Edge で http://localhost:3000 を開く
```

1. 「測定する」を押して、ふだんの声で5秒ほど話す
2. なりたい声を選ぶ(細かい調整もできる)
3. **ヘッドホンをつけて**「変換スタート」、または録音・ファイルを変換して保存(WAV)

### Discord・配信で使う

1. 仮想オーディオケーブル(例:VB-CABLE)をインストール
2. このアプリの「出力先」を **CABLE Input** にする
3. Discord・OBS などのマイクを **CABLE Output** にする

## 限界と、もっと自然にしたいとき

この方式は「あなたの声を加工する」ものなので、聞き慣れた人が注意して聞くと加工だとわかることがあります。
**「ボイチェンだと気づかれないレベル」を目指すなら、AIで声そのものを置き換える方式**が必要です → [`AI版の手順.md`](AI版の手順.md)

## ファイル

| ファイル | 内容 |
|---|---|
| `public/voice-processor.js` | 声の変換の本体(AudioWorklet)。リアルタイムとファイル変換で共通 |
| `public/app.js` | 画面・声の高さの測定・録音・WAV書き出し |
| `server.js` | ファイルを配るだけのサーバー(マイクは localhost か https でしか使えないため) |
