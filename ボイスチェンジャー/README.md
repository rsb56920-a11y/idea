# ナチュラルボイスチェンジャー

地声(例:41歳男性・約100Hz)から、女の子・お姉さん・美少年・両声類(中性)・ショタ・低音イケボの声に変えるボイスチェンジャーです。
ブラウザだけで動き、**音声はどこにも送信しません**。

## 自然に聞こえる理由

| よくある安いボイスチェンジャー | これ |
|---|---|
| 声の高さだけ上げる → 「ヘリウム声」「早回し声」 | 声の高さ(ピッチ)と響き(フォルマント)を**別々に**動かす |
| 全員同じ設定 | **あなたの声を測って**(高さ・抑揚の幅・声道の長さ)、あなた専用の変換量を計算 |
| 倍音をばらばらにずらす → 濁る・ガラガラする | 倍音の山ごとにまとめてずらし、位相の関係を保つ |
| 子音(さ行・た行)まで高くなって舌足らずに | 声(有声音)だけ高さを変え、息の音(子音)は変えない |
| 抑揚が男性のまま | 抑揚の幅をなりたい声に合わせて広げる |
| 息の成分がなく、機械っぽい | 高い音域に、響きの形に沿った息の音を足せる |

### 2つの変換エンジン

| | リアルタイム | 高品質(録音・ファイル用) |
|---|---|---|
| しくみ | 位相ロック方式のフェーズボコーダ | 声を「高さ・響き・息」に分けて1から作り直す(WORLD と同じ考え方) |
| 使いどころ | 配信・通話 | 録音した声・動画のナレーション |
| 速さ | 遅れ 約0.05〜0.1秒 | 10秒の声を約2〜5秒で変換 |

### 数字での確認(合成音でのテスト)

「100Hzの男声」を「女の子」に変換し、理想の女声(同じ話し方で、声帯と声道だけ女性)と比べました。
耳で聞いての評価ではないので、最終的にはあなたの声で聞きくらべてください。

| 項目 | 改善前 | リアルタイム(今) | 高品質(今) | 理想 |
|---|---|---|---|---|
| 倍音の強さのずれ(小さいほど良い) | 4.1dB | 1.1dB | 0.9〜1.3dB | 0 |
| 倍音のきれいさ(大きいほど良い・濁りの少なさ) | 4〜6dB | 35〜39dB | 23〜26dB | 37〜39dB |
| 声の高さが動く時のずれ | 1オクターブずれる所あり | 18セント | 8セント | 0 |

(セント = 半音の1/100。20セント程度はほとんど気づかない)

## 使い方

```bash
cd ボイスチェンジャー
npm start          # 追加のインストールは不要
# → Chrome か Edge で http://localhost:3000 を開く
```

1. 「測定する」を押して、ふだんの声で5秒ほど話す
2. なりたい声を選ぶ(細かい調整もできる)
3. **ヘッドホンをつけて**「変換スタート」、または録音・ファイルを変換して保存(WAV)

### Discord・Twitch・OBS で使う(パソコン)

1. 仮想オーディオケーブル **VB-CABLE**(無料)をインストールして再起動
2. このアプリの「変換した声の出力先」を **CABLE Input** にする
3. 自分の声を聞きたいときは「モニター」にチェックして、出力先をヘッドホンにする
4. **OBS**:「音声入力キャプチャ」→ デバイス **CABLE Output**。元のマイクは OBS でミュート
5. **Discord**:設定 → 音声・ビデオ → 入力デバイス **CABLE Output**。Discord のノイズ抑制はオフがおすすめ
6. 配信中はこのタブを閉じない

### スマホで使う

スマホでは、マイクは **https のページ**でしか使えません。このフォルダーの `public` をそのまま GitHub Pages・Netlify などの無料の静的ホスティングに置けば動きます(サーバーの処理は不要)。

| できること | スマホ |
|---|---|
| 録音・ファイルの変換(高品質) | ○ |
| リアルタイム変換をイヤホンで聞く | ○(有線イヤホン推奨。Bluetooth は遅れが大きい) |
| 変換した声をそのまま Discord アプリの通話に流す | ✕(スマホには仮想オーディオケーブルがないため)→ 録音して音声メッセージで送る |

## 限界と、もっと自然にしたいとき

この方式は「あなたの声を加工する」ものなので、聞き慣れた人が注意して聞くと加工だとわかることがあります。
**「ボイチェンだと気づかれないレベル」を目指すなら、AIで声そのものを置き換える方式**が必要です → [`AI版の手順.md`](AI版の手順.md)

## ファイル

| ファイル | 内容 |
|---|---|
| `public/voice-processor.js` | リアルタイム変換(AudioWorklet) |
| `public/hq-engine.js` / `hq-worker.js` | 高品質エンジン(声を作り直す)と、それを裏で動かす Worker |
| `public/voice-analysis.js` | あなたの声の分析(高さ・抑揚の幅・声道の長さ) |
| `public/capture-processor.js` | 測定用に、マイクの音を圧縮せずに受け取る |
| `public/app.js` | 画面・声の高さの測定・録音・WAV書き出し |
| `server.js` | ファイルを配るだけのサーバー(マイクは localhost か https でしか使えないため) |
