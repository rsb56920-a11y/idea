# 「ボイチェンだと気づかれない」レベルを目指す:AI版の手順

このフォルダーのボイスチェンジャーは「あなたの声を加工する」方式です。
さらに自然にするには、**AIが声そのものを別の声に置き換える方式(AIボイスチェンジャー)**を使います。
話し方・抑揚はあなたのまま、声質だけが学習した声になるので、加工っぽさがほとんど出ません。

> ここに書いたソフトの名前・動作条件は変わることがあります。必ず各ソフトの公式ページで最新の手順と利用規約を確認してください。

## 必要なもの

| もの | 目安 |
|---|---|
| Windows パソコン | リアルタイムで使うなら **NVIDIA の GPU** があると安定しやすい(ソフトによってはCPUだけでも動く) |
| マイク | USBマイクなど。部屋の反響が少ないほど良い |
| 仮想オーディオケーブル | VB-CABLE など(Discord・配信に流す場合) |
| **声のモデル** | 変換先の声。**使ってよいと明記されたもの**を使う(下の注意を参照) |

## 代表的な方式

| 方式 | 特徴 |
|---|---|
| **RVC** | AIボイスチェンジャーで広く使われている方式。自然さが高い。リアルタイムでは GPU があると安心 |
| **Beatrice** | 日本で開発されている低遅延のAIボイスチェンジャー。CPUでも動かしやすいことを重視している |

リアルタイムで使う場合は、これらのモデルを読み込んで動かせる「リアルタイム ボイスチェンジャー クライアント」系のソフトを使うのが一般的です(例:w-okada 氏の VC Client)。

## 大まかな流れ

1. 公式ページから、リアルタイム変換用のソフトをダウンロードして起動
2. 使ってよい声のモデルを用意して読み込む
3. 入力をマイク、出力を VB-CABLE にする
4. ソフトの「ピッチ(音程)」を、あなたの声(約100Hz)から女声なら **+12前後** に合わせる
5. Discord・OBS のマイクを CABLE Output にする

## 大事な注意(必ず守ってください)

- **実在の人(声優・VTuber・歌手・知人など)の声を、本人の許可なく学習・使用しない。** 肖像権・パブリシティ権の問題や、なりすまし・詐欺と見なされるおそれがあります
- 配布されているモデルは、**利用規約で「ボイスチェンジャーとしての利用」「配信での利用」「商用利用」が許可されているか**を確認する
- 自分の声を自分で学習させるのは問題ありません
- 変えた声で他人をだます(なりすまし、恋愛目的の詐欺、成りすまし通話など)使い方は絶対にしない

## このアプリとの使い分け

| | このアプリ(加工方式) | AI方式 |
|---|---|---|
| 自然さ | 自然寄り。注意して聞くと加工とわかることがある | かなり高い |
| 準備 | なし(ブラウザで開くだけ) | ソフトとモデルの用意が必要 |
| パソコンの性能 | 普通のPCでOK | GPU があると安定 |
| 声の種類 | 設定しだいで何にでも | 用意したモデルの声 |
