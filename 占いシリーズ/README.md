# 占いシリーズ(6本・AI代ゼロ・サーバー代ゼロ)

いまの流行りに乗った占いを6本。**どれもダブルクリックで動く1ファイル**です。
結果はスマホで見やすく、**インスタ/X向けの結果画像(1080x1350)** をワンタップで保存できるので、シェアで広がりやすい作りです。

| ファイル | 流行りポイント | 無料で見られる | 完全版(有料) |
|---|---|---|---|
| 天中殺チェッカー.html | **2026-2027年は午未天中殺**で検索が増える | 天中殺タイプ・時期・本質 | 36か月カレンダー・やっていい/避けたいこと・開運7 |
| 数秘術2027年の運勢.html | 年末は「来年の運勢」が一番売れる時期 | 2027年のテーマ・運気・ラッキー | 12か月の運勢・勝負月・恋愛/仕事/お金 |
| 推し相性占い.html | **推し活**。推しの名前入りでシェアされやすい | 運命度%・関係タイプ | 前世・応援のしかた・60日の推し活開運日 |
| 韓国式サジュ診断.html | 韓国で大流行の「サジュ(사주)」 | 10タイプ診断 | 2027年運勢・恋愛・相性・仕事・お金 |
| 今日のタロット.html | 毎日カードが変わる→毎日来てもらえる | 今日の1枚 | スリーカード・恋愛/仕事/お金 |
| オーラカラー診断.html | プロフ画像にしたくなる「色」診断 | メイン/サブのオーラ | 2027年のオーラ・開運・相性 |

- `index.html` … 6本の入口ページ
- `設定.js` … サイト名・販売URL・合言葉(メモ帳で書きかえ)
- `合言葉メーカー.html` … 完全版をひらく合言葉を作る道具

## しくみ

1. 無料で結果を見せる → 画像保存/Xシェアで広がる
2. 下に「完全版」のぼかし見本+購入ボタン(`設定.js` の `payUrl`)
3. 買った人は決済完了画面の「合言葉」を入れると、その端末でずっと見られる

計算はすべてブラウザの中。入力した生年月日はどこにも送信されません(個人情報を持たないので安心・安全)。

## 公開のしかた(無料)

1. `設定.js` の **合言葉を必ず変える**(`合言葉メーカー.html` で作る。見本のまま公開すると誰でも開けます)
2. Stripe の「支払いリンク」を作り、完了ページのメッセージに合言葉を書く → そのURLを `payUrl` に貼る
3. このフォルダ(`src` はなくてOK)を [Netlify Drop](https://app.netlify.com/drop) にドラッグ → 公開URLを `siteUrl` に書いてもう一度ドラッグ

くわしくは `販売方法/06_占いシリーズの売り方.md`。

## 作り直し(開発者向け)

中身は `src/` にあります。`python scripts/build-uranai.py` で6本と入口ページを作り直します。
新しい占いを増やすときは `src/products/` に1ファイル足して `src/order.json` に id を足すだけ。
