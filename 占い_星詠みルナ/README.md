# 星詠みルナ — AI占い・診断アプリ

AI占い師「ルナ」が鑑定する、スマホ向けの占いWebアプリです。

## メニュー

| メニュー | 入力 | 結果 |
|---|---|---|
| 今日の運勢 | 名前・生年月日 | 総合運スコア、恋愛/仕事/金運/対人運 |
| タロット占い | 名前・悩み → カードを3枚選ぶ | 過去/現在/未来/相談への答え |
| 相性診断 | ふたりの名前・誕生日・関係 | 相性度、うまくいくポイントなど |
| 前世診断 | 名前・生年月日 | 「あなたの前世は〇〇」、才能・課題など |

## 売るための仕組み

- **無料部分:** 見出し・スコア・要約(続きが気になるところで止める)・ラッキーアイテム
- **有料部分(詳細鑑定 ¥300):** 4項目の詳しい鑑定。ぼかし表示+購入ボタン
- **拡散:** 𝕏 投稿ボタン、結果をSNS用画像(1080×1350)で保存・共有
- **招待リンク(相性診断):** 結果画面から相手に送ると、相手側は「〇〇さんがあなたとの相性を占いました」と表示され、名前入りで診断が始まる(誕生日はリンクに含めない)
- **リピート:** 「今日の運勢」は毎日内容が変わる。名前・誕生日を記憶して2回目から入力を省略

### 有料部分の守り方

- 無料鑑定では「見出し・スコア・要約・ラッキーアイテム」だけをAIで作ります。**詳細鑑定の本文はまだ存在しません**。
- 購入ボタンを押すと、サーバーが購入を確認してから詳細鑑定を作って返します。お金を払わずに中身を見ることはできません。
- AIの利用料金も、詳細鑑定は買った人の分しかかからないので、大きく下がります(→ `販売方法/01_占い_販売計画.md`)。
- 無料鑑定の内容には改ざん防止の署名を付け、詳細鑑定の時に送り返してもらいます。サーバーにデータを保存しなくても、本当に占った内容の続きだけを書けます。

### 決済

- `STRIPE_SECRET_KEY` を設定すると、「続きを読む」から Stripe の支払いページに移動し、支払い完了を確認してから詳細鑑定を開きます。
- 設定しない場合はデモ(購入ボタンを押すだけで開く)です。
- つなぎ方は `販売方法/04_Stripe決済のつなぎ方.md` を見てください。

## 起動方法

```bash
cd 占い_星詠みルナ
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 未設定ならデモモード
npm start   # → http://localhost:3000
```

| 環境変数 | 説明 | 既定値 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API キー | なし(デモモード) |
| `CLAUDE_MODEL` | 使用モデル | `claude-opus-5` |
| `RATE_LIMIT_PER_HOUR` | 1IPあたり1時間の鑑定回数上限(API料金の使いすぎ防止) | `20` |
| `READING_SECRET` | 鑑定データの署名に使う鍵(本番では長いランダムな文字列を固定で設定) | 起動ごとにランダム |
| `STRIPE_SECRET_KEY` | Stripe のシークレットキー。設定すると本物の決済になる | なし(デモ) |
| `PUBLIC_URL` | 公開URL。Stripe の支払い後に戻ってくる先 | アクセスされたホスト |
| `PRICE_JPY` | 詳細鑑定の価格(円) | `300` |
| `PAYMENT_MODE` | 決済方式を強制したい時だけ(`demo` / `stripe`) | キーがあれば `stripe` |
| `PORT` | ポート | `3000` |
