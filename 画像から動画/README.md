# 画像から動画メーカー

写真を入れるだけで、ゆっくり動く(ケン・バーンズ効果)おしゃれなスライドショー動画を作るアプリです。
ブラウザだけで動き、**画像はどこにも送信しません**。

## できること

- 画像を何枚でも追加(ドラッグ＆ドロップ可)、並べ替え・削除
- サイズ:縦 9:16(TikTok・リール・ショート)/正方形 1:1/横 16:9
- 収め方:全体を見せる(余白はぼかした画像で埋める)/画面いっぱい
- 動き:ズームイン・ズームアウト・左右・上へ流れる(おまかせで1枚ずつ変わる。1枚ごとにも変更可)
- 切り替え:クロスフェード・スライド・ズーム・フラッシュ
- 1枚ごとの文字入れ(縁取り付きの白文字、ふわっと表示)
- キラキラ(光の粒)、BGM(最後は自動でフェードアウト)、最後は暗くなって終わる
- 書き出し:MP4(Chrome・Edge の最新版)、非対応のブラウザでは WebM

## 使い方

```bash
cd 画像から動画
npm start          # 追加のインストールは不要
# → Chrome か Edge で http://localhost:3000 を開く
```

書き出しには動画と同じ時間がかかります(10秒の動画なら約10秒)。書き出し中はタブを開いたままにしてください。

## 写真の人や物を「動かしたい」場合

このアプリは写真の中身はそのままで、カメラが動いているように見せる方式です。
写真の人物がまばたきする・髪がなびくといった動きは、**AI動画生成サービス**(画像から動画を作る機能を持つもの)を使います。
- 多くは有料・クレジット制で、1本数十秒〜数分かかります
- 他人の写真や、権利のない画像を動かして公開しないでください(肖像権・著作権)

## 販売するなら

- TikTok・リールを毎日投稿する人・お店向けに「写真を入れるだけで投稿用動画」として出せる
- 追加するとよい機能の例:テンプレート(誕生日・旅行・お店紹介)、文字のデザイン選択、ロゴ(透かし)の自動挿入
