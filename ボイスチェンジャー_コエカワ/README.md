# コエカワ — ナチュラルボイスチェンジャー

地声(例:41歳男性・約100Hz)から、女の子・お姉さん・美少年・両声類(中性)・ショタ・低音イケボの声に変えるボイスチェンジャーです。
ブラウザだけで動き、**音声はどこにも送信しません**。

## 自然に聞こえる理由

| よくある安いボイスチェンジャー | これ |
|---|---|
| 声の高さだけ上げる → 「ヘリウム声」「早回し声」 | 声の高さ(ピッチ)と響き(フォルマント)を**別々に**動かす |
| 全員同じ設定 | **あなたの声を測って**(高さ・抑揚の幅・声道の長さ)、あなた専用の変換量を計算 |
| 倍音をばらばらにずらす → 濁る・ガラガラする | 倍音の山ごとにまとめてずらし、位相の関係を保つ |
| 子音(さ行・た行)まで高くなって舌足らずに | 声(有声音)だけ高さを変え、息の音(子音)は変えない |
| 抑揚が男性のまま | 抑揚の幅をなりたい声に合わせて広げる |
| 息の成分がなく、機械っぽい | 高い音域に、響きの形に沿った息の音を足せる |
| 規則正しすぎるパルスでブザーっぽい | **声のゆらぎ**: 人の声帯のように、1回ごとの間隔(ジッター 約0.3%)と強さ(シマー 約0.25dB)を少しだけゆらす |
| 母音の途中で一瞬「無声」と判定され、声に雑音がブツッと混ざる | 直前まで声で高さも同じなら声のまま続ける判定。話し始めは、ふだんの高さ(±5半音)に近いときだけ声と判定して裏返りを防ぐ(高さの正確さ 約77%→84%、裏返りは半分以下) |
| 声の質感が男性のまま硬い | 「やわらかさ」: 第1倍音を強める(女性の声は第1倍音が第2倍音より強い、という研究で知られた特徴) |

### 3つの変換エンジン

| | 作り直し(リアルタイム・おすすめ) | 軽量(リアルタイム) | 高品質(録音・ファイル用) |
|---|---|---|---|
| しくみ | 5msごとに声の高さ・響き・息を調べ、声を作り直す | 位相ロック方式のフェーズボコーダ | 前後も見て声を1から作り直す(WORLD と同じ考え方) |
| 使いどころ | 配信・通話 | 古いパソコン・スマホ | 録音した声・動画のナレーション |
| 遅れ・速さ | 約31ms | 約32ms | 10秒の声を約2〜5秒で変換 |
| CPU の目安 | 1コアの約17% | 約8% | — |

リアルタイム2方式の比較(日本語の読み上げ音声):

| 項目 | 軽量 | 作り直し |
|---|---|---|
| 声の高さが目標どおり | 70% | **77%** |
| 同(部屋の雑音あり) | 65% | **77%** |
| 高さが動く時のずれ | 18セント | **11セント** |
| 高さが動く時の倍音のきれいさ(理想 1.5dB) | -0.2dB | **1.7dB** |
| 子音の音量(元との差) | +0.8dB | +1.6dB |

### 数字での確認(合成音でのテスト)

「100Hzの男声」を「女の子」に変換し、理想の女声(同じ話し方で、声帯と声道だけ女性)と比べました。
耳で聞いての評価ではないので、最終的にはあなたの声で聞きくらべてください。

| 項目 | 改善前 | リアルタイム(今) | 高品質(今) | 理想 |
|---|---|---|---|---|
| 倍音の強さのずれ(小さいほど良い) | 4.1dB | 1.1dB | 0.9〜1.3dB | 0 |
| 倍音のきれいさ(大きいほど良い・濁りの少なさ) | 4〜6dB | 35〜39dB | 23〜26dB | 37〜39dB |
| 声の高さが動く時のずれ | 1オクターブずれる所あり | 18セント | 8セント | 0 |

(セント = 半音の1/100。20セント程度はほとんど気づかない)

日本語の読み上げ音声(音声合成 espeak-ng で作った約100Hzの男声、子音あり)での確認:

| 項目 | リアルタイム | 高品質 |
|---|---|---|
| 声の高さが目標どおりの割合 | 49% → **69%**(音節の頭で高さが遅れて上がる「しゃくり」を修正) | 62% → **82%**(息の足しすぎを修正) |
| 声のはっきりさ(元の声 0.90) | 0.74 → **0.82** | 0.73 → **0.87** |
| 子音の音量(元の声との差・0に近いほど良い) | +3.1dB → **+0.8dB**(声と子音で音量合わせを分けた) | +0.7dB |
| 部屋の雑音があるとき(声より20dB小さいファンの音) | 高さが正しい 65% | 高さが正しい 81% |
| 話していない時の雑音の質(平坦度・元 0.28) | 0.30(「ポコポコ音」にならない) | 0.27 |

## 使い方(いちばん簡単)

1. **`コエカワ.html` をダブルクリック**(Chrome か Edge で開く。インストールもネット接続も不要)
2. 「測定する」を押して、ふだんの声で6秒ほど話す(あなた専用の設定が作られる)
3. なりたい声を選ぶ(細かい調整もできる。気に入った設定は「マイ設定」に名前をつけて保存)
4. **ヘッドホンをつけて**「変換スタート」、または録音・ファイルを変換して保存(WAV)
5. 録音の変換では「両方の方式で変換して聞きくらべ」で、あなたの声でどちらが自然か確かめられる
7. **🎙 お手本の声に合わせる**:なりたい声の録音ファイルを選ぶと、その声の高さ・響き(声道の長さ)・抑揚を測って、あなたの声から近づける設定を自動で作ります(合成音のテストで、高さ 220Hz→224Hz、響き 1.2倍→1.24倍)。使ってよい声だけにしてください
6. 変換中は **🎯 話し方トレーナー** が出ます。変換後の声の高さがグラフになり、なりたい声の自然な高さの帯と比べて「低め」「抑揚が小さめ」などをアドバイスします(お金も追加の道具もいらない、いちばん効く自然さの上げ方)

> 初めてマイクを使うときは、ブラウザに「マイクの使用を許可しますか?」と出るので「許可」を押してください。

### サーバーで動かす場合(開発用・スマホ公開用)

```bash
cd ボイスチェンジャー_コエカワ
npm start   # → http://localhost:3000
```

`public/` の中を直したら、`python3 scripts/build-koekawa.py` で `コエカワ.html` を作り直します。

### Discord・Twitch・OBS で使う(パソコン)

1. 仮想オーディオケーブル **VB-CABLE**(無料)をインストールして再起動
2. このアプリの「変換した声の出力先」を **CABLE Input** にする
3. 自分の声を聞きたいときは「モニター」にチェックして、出力先をヘッドホンにする
4. **OBS**:「音声入力キャプチャ」→ デバイス **CABLE Output**。元のマイクは OBS でミュート
5. **Discord**:設定 → 音声・ビデオ → 入力デバイス **CABLE Output**。Discord のノイズ抑制はオフがおすすめ
6. 配信中はこのタブを閉じない

### スマホで使う

スマホでは、マイクは **https のページ**でしか使えません。このフォルダーの `public` をそのまま GitHub Pages・Netlify などの無料の静的ホスティングに置けば動きます(サーバーの処理は不要)。

| できること | スマホ |
|---|---|
| 録音・ファイルの変換(高品質) | ○ |
| リアルタイム変換をイヤホンで聞く | ○(有線イヤホン推奨。Bluetooth は遅れが大きい) |
| 変換した声をそのまま Discord アプリの通話に流す | ✕(スマホには仮想オーディオケーブルがないため)→ 録音して音声メッセージで送る |

## 限界と、もっと自然にしたいとき

この方式は「あなたの声を加工する」ものなので、聞き慣れた人が注意して聞くと加工だとわかることがあります。
**「ボイチェンだと気づかれないレベル」を目指すなら、AIで声そのものを置き換える方式**が必要です → [`AI版の手順.md`](AI版の手順.md)

## ファイル

| ファイル | 内容 |
|---|---|
| `public/resynth-processor.js` | リアルタイム変換・作り直し方式(AudioWorklet) |
| `public/voice-processor.js` | リアルタイム変換・軽量方式(AudioWorklet) |
| `public/hq-engine.js` / `hq-worker.js` | 高品質エンジン(声を作り直す)と、それを裏で動かす Worker |
| `public/voice-analysis.js` | あなたの声の分析(高さ・抑揚の幅・声道の長さ) |
| `public/capture-processor.js` | 測定用に、マイクの音を圧縮せずに受け取る |
| `public/app.js` | 画面・声の高さの測定・録音・WAV書き出し |
| `コエカワ.html` | 全部を1つにまとめた版(ダブルクリックで動く) |
| `server.js` | ファイルを配るだけのサーバー(開発・スマホ公開用) |
