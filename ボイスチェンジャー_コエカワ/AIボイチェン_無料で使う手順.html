🤖 AIボイチェンを無料で使う

コエカワより、ぐっと「本物の女声」に近づける方法(RTX 3050 / VRAM 4GB 向け)

コエカワとAIボイチェンのちがい

コエカワ(いまのもの)AIボイチェン(このページ)
しくみあなたの声の「高さ」と「響き」を計算で動かすAIが、あなたの話した内容を別の人の声色で作り直す
女声らしさがんばっても男性っぽさが残りやすい声色はほぼ女性になる(話し方のクセは残る)
重さとても軽い(ブラウザだけ)重い(グラフィックボードを使う)
準備ダブルクリックだけ数GBのダウンロード+声モデル選び
お金無料無料(ソフトもサンプルの声も無料)
💡 AIは「声色」を変えますが、高さの使い方(抑揚・語尾)はあなたのままです。コエカワの 🎓 話し方レッスン で練習した話し方は、AIでもそのまま効きます。両方使うのがいちばん自然です。

使うもの(すべて無料)

  • VCClient(作者: w-okada さん)… リアルタイムAIボイスチェンジャー。Pythonは不要で、解凍して起動するだけ。
    公式ページ: https://github.com/w-okada/voice-changer
  • VB-CABLE … コエカワで入れたものをそのまま使います(まだなら https://vb-audio.com/Cable/)
  • 声モデル … 「どんな声にするか」のデータ。VCClientにサンプルが入っています(規約に注意)
⚠️ このページは VCClient の公式説明をもとに書いています。私のほうでは Windows 上で実際に動かして確かめられていないため、ボタンの名前や画面の並びが、版によって少しちがうことがあります。わからないところがあれば、そのときの画面の様子を教えてください。

1. ダウンロードと起動

✅ かんたんな方法: 同じフォルダの AIボイチェン\AIボイチェンを入れる.bat をダブルクリックするだけ。最新版を自動で探してダウンロードし、F:\VCClient に入れて起動します(2回目からは起動だけ)。
数GBあるので時間がかかります。黒い画面は閉じずに待ってください。エラーが出たら、その画面のスクショを送ってください。

自分で入れる場合は、次の手順です。

  1. 公式ページ github.com/w-okada/voice-changer を開き、説明にあるダウンロード先(Hugging Face の wok000/vcclient000)へ進みます。
  2. 一覧から Windows 用で、名前に cuda が入ったいちばん新しい zip を選んでダウンロード(NVIDIA のグラボ用。数GBあります)。
    ※ グラボを LoL に使いたくて重いときは、名前に std が入った版(CPUで動く軽い「Beatrice v2」方式)もあります。
  3. zip を右クリック → すべて展開 → 展開先を F:\VCClient にします(前の版があっても、新しいフォルダに)。
  4. フォルダの中の start_http.bat をダブルクリック。黒い画面が出ますが、閉じずにそのまま待ちます。
  5. 初回は必要なデータを自動でダウンロードします(1〜2分)。ブラウザが開いたら START を押します。
💡 Windows の「PCが保護されました」が出たら 詳細情報 → 実行。ウイルス対策ソフトに止められたら、公式からダウンロードしたものなら許可してOKです。

2. 声を選んで、変換してみる

  1. 画面の声モデルの一覧から、サンプルの女性の声(例: つくよみちゃん)を選びます。
  2. 入力(input) … あなたのマイク
  3. 出力(output) … まずはヘッドホンで確認。配信で使うときは CABLE Input
  4. TUNE(高さ) … 男性→女性は +10〜+12 くらいから(あなたの声 約145Hz なら +10 前後がおすすめ)。高すぎ・低すぎを耳で調整。
  5. 話してみて、女性の声になれば成功!
✅ はじめは「クライアント(client)」の使い方がおすすめ(公式の説明より)。ブラウザのノイズ抑制も使えます。

3. RTX 3050(VRAM 4GB)で軽く動かす設定

設定おすすめ意味
F0 Det(高さの検出)rmvpe(グラボ)/ 重いときは dio声の高さの読み取り方。rmvpe が正確、dio がいちばん軽い
CHUNKまず 256 → 音がブツブツ切れるなら 512 → 1024一度に変換する長さ。大きいほど安定、そのぶん遅れが増える
EXTRA小さめから前の音をどれだけ参考にするか。大きいほど品質↑・重さ↑↑
遅れの目安画面の buf と res「buf が res より大きい」状態なら途切れません
💡 LoL と同時に使うとき: LoL のフレームレート上限を 60〜120 にしておくと、グラボに余裕ができて途切れにくくなります。それでも重ければ std 版(CPU で動く Beatrice v2) に切り替えます。

4. OBS・Discord・配信セットで使う

  1. VCClient の出力を CABLE Input にする
  2. OBS の「マイク」ソースのデバイスを CABLE Output にする(元のマイクはミュート)
  3. Discord は 設定 → 音声 → 入力デバイスを CABLE Output(Discord 側のノイズ抑制はオフ推奨)
  4. 夜華カナタ配信セットの口パクは、そのまま動きます(設定.js の micName は「マイク」のまま)

5. ⚠️ 声モデルの規約(とても大事)

声モデルには、その声の持ち主が決めたルールがあります。サンプルに入っている声の主なルールは次のとおりです(公式の説明より)。

声必要なこと・禁止されていること
つくよみちゃんクレジット表記が必要(配信の概要欄などに書く)。人を批判・攻撃する使い方、政治・宗教の呼びかけなどは禁止
あみたろボイスチェンジャーを使っていることを明記し、あみたろ本人が話しているのではないと誰でもわかるようにする必要あり
⚠️ つまり、サンプルの声では「ボイチェンだと絶対わからないようにする」使い方は、規約で認められていない場合があります。使う前に、必ずその声の最新の規約を読んでください。

⚠️ ネットには、有名人・歌い手・アニメキャラの声を勝手に学習した声モデルが出回っていますが、本人の許可のない声は使わないでください(トラブルや権利侵害になります)。
💡 「気づかれない自然な女声」を本気で目指すなら、いちばん確実なのは
① 規約で表記なしの使用も認められている声モデルを探す、または
② 知り合いの女性や声優さんに許可をもらって、その人の声で自分専用の声モデルを作る(学習にはPythonと時間が必要。やりたくなったら手順を作ります)
のどちらかです。

こまったとき

こまりごとやること
音がブツブツ切れるCHUNK を大きく(512 → 1024)、F0 Det を dio に
遅れが大きいCHUNK を小さく。EXTRA を小さく
声が高すぎ・低すぎ・裏返るTUNE を ±1〜2 ずつ調整
ゲームがカクつくLoL のフレームレート上限を下げる。std 版(CPU)に切り替える
話し方がだらっと遅く聞こえる・言葉の間に「フー」と音が残るAIは無音のすき間にも音を作ってしまうことがあります。VCClient の無音のしきい値(S.Thresh など)を上げて、話していない時は音を止めます。OBS 側でも「ノイズゲート」フィルタを追加すると確実です
起動しないフォルダを F:\VCClient のような短い英数字の場所に置き直す。黒い画面のエラーを教えてください
