# ココロタイプ — 16タイプ性格診断

16問に答えるだけで、16タイプのどれかがわかる性格診断アプリです。

## 売れる理由

- **無料の診断はAIを使わない**(回答から計算するだけ)→ 無料ユーザーが何人来てもAI代は ¥0
- AIを使うのは **有料のパーソナルレポート(¥300)だけ** → 1件売れるたびにほぼ利益になる
- **友達と相性をくらべる招待リンク** → 送られた人が診断すると、ふたりの相性(%)が出る。利用者が利用者を呼ぶ
- 結果をSNS用画像(1080×1350)で保存、𝕏投稿(`#ココロタイプ #性格診断`)、リンクは画像付きカードで表示
- 16タイプの紹介ページがあり、「自分の友達は何タイプ？」と回遊しやすい
- スマホのホーム画面に追加できる

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 診断スタート、前回の結果、16タイプ一覧、友達からの招待表示 |
| 質問 | 16問を1問ずつ。5段階の丸ボタンで答えると自動で次へ |
| 結果 | タイプ・特徴・4つの傾向(%)・相性のいいタイプ・友達との相性・有料レポート・シェア |
| タイプ紹介 | 16タイプそれぞれの説明 |
| 法律ページ | 特定商取引法に基づく表記・プライバシーポリシー・利用規約(`shop.json` を書き換える) |

## 起動方法

```bash
cd 性格診断_ココロタイプ
npm install
npm start   # → http://localhost:3000
```

| 環境変数 | 説明 | 既定値 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API キー(有料レポートに使う) | なし(レポートはデモ文) |
| `STRIPE_SECRET_KEY` | Stripe のシークレットキー。設定すると本物の決済になる | なし(デモ決済) |
| `PUBLIC_URL` | 公開URL。Stripe の戻り先とリンクカード画像に使う | アクセスされたホスト |
| `READING_SECRET` | 診断データの署名に使う鍵(本番では固定値を設定) | 起動ごとにランダム |
| `PRICE_JPY` | レポートの価格(円) | `300` |
| `CLAUDE_MODEL` | 使用モデル | `claude-opus-5` |
| `RATE_LIMIT_PER_HOUR` | 1IPあたり1時間のレポート作成回数の上限 | `20` |

質問と16タイプの内容は `public/data.js` で変更できます。画像を作り直すときは `node tools/make-images.cjs`。

> 「MBTI」は登録商標のため、名前・説明には使っていません。宣伝でも使わないでください。
