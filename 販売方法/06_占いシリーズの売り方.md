# 占いシリーズの売り方(6本)

## 1. 何を売るか(3つの売り方、組み合わせOK)

| 売り方 | 値段の目安 | やること |
|---|---|---|
| **A. 完全版の合言葉を売る** | 1本 300〜500円 / 6本セット 980円 | Stripe支払いリンク・note有料記事・BOOTH に合言葉を置く |
| **B. 占いサイトのテンプレとして売る** | 1,980〜4,980円 | 占い師さん・Vtuber・インフルエンサー向けに BOOTH/ココナラで「自分の名前で出せる占いサイト」として販売 |
| **C. 広告・アフィリエイト** | クリック次第 | 無料結果の下に電話占い・パワーストーン等のアフィリエイトを貼る(ASPに登録) |

最初は **A(6本セット980円)+ B** がおすすめ。原価ゼロ・在庫ゼロです。

## 2. 売れる時期カレンダー

| 時期 | 押す占い | 理由 |
|---|---|---|
| 10〜12月 | 数秘術2027 / サジュ2027 | 「来年の運勢」の検索が一番伸びる |
| 12〜2月 | 天中殺チェッカー | 年の変わり目+節分(立春)で「天中殺」検索が増える。2026-27は午未天中殺の人 |
| 推しの誕生日・ライブ前 | 推し相性 | 推しの名前でシェアされる |
| 毎日 | 今日のタロット | 朝の投稿で毎日来てもらう |
| 春(新生活) | オーラカラー | プロフィール画像の変更シーズン |

## 3. 集客(無料でできる)

- **X**: 毎朝7時に「今日のタロット」の結果画像を投稿(#今日のタロット)。週1で天中殺・推し相性のネタ投稿
- **TikTok/リール**: 結果画像を3枚スライドにして「○○天中殺の人、2027年は…」の形で投稿
- **固定ポスト**: 入口ページ(index.html)のURL
- 投稿テンプレ:
  - 「2026-2027年、午未天中殺の人は要注意…🌑 自分の天中殺は生年月日だけでわかります → URL」
  - 「推しとの運命度、92%だった人いる?💘 → URL #推し運命度」
  - 「来年のテーマ、数秘術で出したら“成功と豊かさの年”だった🔢 → URL #数秘術2027」

## 4. 支払いのつなぎ方(Stripe・コードいらず)

1. Stripe ダッシュボード → 支払いリンク → 商品「占い完全版セット」980円
2. 「支払い後」→「確認ページを表示」→ メッセージに「合言葉: ○○○○」を書く
3. できたURLを `占いシリーズ/設定.js` の `payUrl.all` に貼る
4. 合言葉のハッシュを `合言葉メーカー.html` で作って `allPassHash` に貼る
5. 合言葉は月に1回変えると、ネットに出回っても被害が小さくなります

> ⚠️ 口座番号やStripeの秘密キーは、ファイルにもチャットにも書かないでください(Stripeの管理画面にだけ登録)。

## 5. 注意(法律まわり)

- 有料で売るときは **特定商取引法に基づく表記** が必要(Stripe/BOOTH/noteの仕組みに沿って表示)
- 「必ず当たる」「不幸になる」など不安をあおる表現はしない(ページ下に「占いは楽しむためのものです」と表示済み)
- 合言葉方式はかんたんな仕組みなので、くわしい人には解除される可能性があります。低価格の商品向けです
