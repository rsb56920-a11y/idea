# 占い「星詠みルナ」販売計画

## 誰に売るか

- **メイン:** 10代後半〜30代の女性。恋愛・片思い・人間関係に悩んでいる人
- **場面:** 寝る前のスマホ、友達との話のネタ、SNSで話題の診断をやってみる時

## 値段(案)

| 商品 | 値段 | ねらい |
|---|---|---|
| 無料鑑定 | ¥0 | 入口。点数と要約だけ見せて「続きが気になる」状態にする |
| 詳細鑑定(1回) | **¥300** | 衝動買いしやすい価格。ジュース2本分 |
| 3回セット | ¥700 | 1回あたり安く見せて客単価を上げる |

最初は **¥300の1回買いだけ** で始めて、よく買う人が出てきたら月額を追加するのがおすすめです。

## 利益の計算(目安)

> 数字はすべて概算です。公開後に実際の利用ログで確認してください。
> 為替は 1ドル=150円 で計算しています。

**AI代(1回の鑑定あたり)**
入力 約800トークン、出力 約1,700トークンと仮定した場合:

| モデル | 1回あたり |
|---|---|
| Claude Opus 5(今の設定) | 約 ¥7 |
| Claude Sonnet 5 | 約 ¥3 |

**1件売れるまでのコスト**
無料で占った人のうち **3%** が¥300を払うと仮定すると、1件売れるまでに約33回の無料鑑定が発生します。

| | 改善前 | 今の作り(※) |
|---|---|---|
| 売上 | ¥300 | ¥300 |
| 決済手数料(約3.6%) | −¥11 | −¥11 |
| 無料鑑定33回分のAI代 | **−¥231** | −¥80 程度(短い要約だけなので1回約¥2.5) |
| 詳細鑑定1回分のAI代 | (無料時に生成済み) | −¥7 |
| **残る利益** | **約¥58** | **約¥200** |

※ **改善済み:** 無料の時は「タイトル・点数・要約」だけを短く作り、詳細鑑定は**購入後に初めて作る**形に変更しました。
AI代が大きく下がり、同時に「お金を払わずに有料部分を見られてしまう」問題も解決しています。
(実際の金額は、APIキーを入れて公開したあとの利用ログで確認してください)

## 集客

お金をかけずに広げるのが基本です。アプリにはすでに次の仕組みが入っています。

- 結果をSNS用の画像(縦長1080×1350)で保存 → Instagram・X に貼りやすい
- 𝕏 に投稿するボタン(`#星詠みルナ #AI占い` 付き)
- 相性診断の「相手に送る」リンク → 送られた人が次のユーザーになる

**やること**

1. **TikTok / Instagram リール:** 「AIに前世を占わせたら〇〇だった」系の短い動画を毎日1本。画面録画でOK
2. **X:** 毎朝「今日の運勢 12星座ランキング」を投稿してアプリに誘導
3. **占い系・恋愛系アカウントへの紹介依頼:** 紹介1件あたり売上の20〜30%を渡す形にすると頼みやすい
4. **推し相性診断で推し活層を狙う:** 「#推し相性診断」付きで投稿される。推しの誕生日・ライブ・新曲発表の日に合わせて「推しとのシンクロ率」を発信すると広がりやすい
   - 実在の人物を推しにする人も多いため、AIには推し本人の私生活を断定しないよう指示済み。公式ロゴや写真は使わないこと(肖像権・商標)
5. **季節イベントに合わせた限定メニュー:** バレンタイン、クリスマス、新年の運勢、受験前など
