# はじめに読む — 売り出すまでの全体像

このフォルダーには、作ったアプリを「実際にお金になる形」にするための手順をまとめています。

## どれから売るべきか

| 順位 | 商品 | 理由 |
|---|---|---|
| **1** | 占い_星詠みルナ | 1回¥300の都度課金で売りやすい/SNSで広まりやすい/1回あたりのAI代が読みやすい |
| 2 | ZETA風チャット | 本家ZETAなど強い競合が多い。売るならニッチ(推し・創作者向け)に絞る |

→ **まずは占いに集中**するのがおすすめです。

## 売り出すまでのチェックリスト

あなたの判断・申し込みが必要なものに ✋ を付けています(ループでは自動で進めません)。

- [ ] ✋ **APIキーを取得**:[Claude Console](https://console.anthropic.com/) でキーを作り、利用上限(月額)を設定
- [ ] ✋ **決済サービスに申し込む**:Stripe などで個人事業主として申請(→ `03_共通_決済・公開・法律.md`)
- [ ] **有料部分をサーバー側で守る**:購入確認後にだけ詳細鑑定を返す作りに変更(開発作業)
- [ ] ✋ **公開先を決める**:Render / Railway などに置く(→ `03_共通_決済・公開・法律.md`)
- [ ] ✋ **独自ドメインを取る**(年1,000〜2,000円程度)
- [ ] **必須ページを作る**:特定商取引法に基づく表記、プライバシーポリシー、利用規約
- [ ] ✋ **SNSアカウントを作る**:X・TikTok・Instagram(→ `01_占い_販売計画.md` の集客)
- [ ] 最初の1週間は無料で配り、シェアされるか・どのメニューが人気かを見る
