# Stripe 決済のつなぎ方(占い_星詠みルナ)

アプリ側の準備はできています。あなたがやるのは **Stripe の申し込みと、キーをサーバーに入れること** だけです。

## お金の流れ

```
お客さん ──¥300──▶ Stripe ──(手数料を引いて自動振込)──▶ あなたの銀行口座
```

- **銀行口座は Stripe の管理画面に登録します。** アプリのコードや、チャット(Claude)には絶対に書かないでください。
- アプリが知っているのは「支払いが完了したかどうか」だけです。カード番号や口座番号をアプリが扱うことはありません。

## 手順

### 1. Stripe に申し込む(あなたの作業)
1. https://stripe.com/jp でアカウントを作る
2. 本人確認・事業の情報・**振込先の銀行口座**を登録する(個人事業主で申請できます)
3. 審査が終わるまでは「テストモード」で試せます

### 2. テストモードで試す
1. Stripe 管理画面 → 開発者 → APIキー で **テスト用シークレットキー**(`sk_test_...`)をコピー
2. アプリを起動するときに環境変数で渡す(**チャットやコードには貼らない**)
   - Windows(PowerShell)
     ```powershell
     cd F:\売れる商品\占い_星詠みルナ
     npm install
     $env:STRIPE_SECRET_KEY="sk_test_..."
     npm start
     ```
3. http://localhost:3000 で占い →「続きを読む」→ Stripe の支払い画面に移動することを確認
4. テスト用カード番号 `4242 4242 4242 4242`(有効期限は未来の日付、CVCは適当な3桁)で支払い
5. アプリに戻って詳細鑑定が開けば成功

### 3. 本番にする
1. Stripe の審査が通ったら、管理画面で本番モードに切り替え、**本番用シークレットキー**(`sk_live_...`)を取得
2. 公開サーバー(Render など)の環境変数に次を設定

| 環境変数 | 値 |
|---|---|
| `STRIPE_SECRET_KEY` | `sk_live_...` |
| `PUBLIC_URL` | 公開したサイトのURL(例 `https://luna.example.com`) |
| `READING_SECRET` | 長いランダムな文字列(一度決めたら変えない) |
| `ANTHROPIC_API_KEY` | Claude の APIキー |
| `PRICE_JPY` | 価格(円)。省略すると 300 |

## アプリ側でやっていること

- 「続きを読む」→ サーバーがその鑑定専用の支払いページを Stripe に作ってもらい、そこへ移動
- 支払い後にアプリへ戻ると、サーバーが Stripe に「支払い完了か」「この鑑定の支払いか」を確認してから詳細鑑定を作る
- 1回の支払いを別の鑑定に使い回すことはできない
- 支払い後に鑑定の作成だけ失敗した場合は、**もう一度払わずに**やり直せる

## 注意

- シークレットキーは「お店の金庫の鍵」です。GitHub・チャット・SNSに絶対に出さないでください。漏れたら Stripe 管理画面ですぐ作り直してください。
- 本番で売る前に、`03_共通_決済・公開・法律.md` の「特定商取引法に基づく表記」などを用意してください(Stripe の審査でも求められます)。
