# 決済・公開・法律(共通)

> 料金や規約は変わることがあります。申し込む前に各サービスの公式ページで最新情報を確認してください。

## 1. 決済

| サービス | 特徴 |
|---|---|
| **Stripe**(おすすめ) | 個人でも申し込める。カード・Apple Pay・Google Pay に対応。手数料は国内カードで約3.6% |
| PAY.JP | 日本の会社。手数料や審査条件は公式で確認 |

**流れ:** 購入ボタン → Stripe の支払い画面 → 支払い完了をサーバーが確認 → 詳細鑑定を表示
(アプリ側は対応済み。手順は `04_Stripe決済のつなぎ方.md`)

## 2. 公開(インターネットに出す)

| サービス | 特徴 |
|---|---|
| Render | Node.js をそのまま置ける。無料枠あり(しばらく使われないと止まる) |
| Railway | 設定が簡単。少額の月額課金 |
| VPS(ConoHa など) | 安いが自分で管理が必要 |

- APIキーはサーバーの「環境変数」に設定する。**コードやGitHubに書かない**
- Claude Console で**月の利用上限**を必ず設定する(想定外の請求を防ぐ)

## 3. 法律で必要なもの

| 必要なもの | 内容 |
|---|---|
| **特定商取引法に基づく表記** | ネットでお金を取るなら必須。販売者名・連絡先・価格・支払い方法・返品について等 |
| **プライバシーポリシー** | 名前・誕生日などを扱うため必要。「占いにだけ使う」「第三者に渡さない」等 |
| **利用規約** | 返金の条件、禁止事項、未成年の利用について |
| **エンタメ表記** | 「占い結果はAIが生成した娯楽です」(アプリには表示済み) |

### 占いアプリでの対応状況

3つのページはアプリに作ってあります(画面の一番下にリンクがあります)。
あなたがやるのは **`占い_星詠みルナ/shop.json` の「【】」の部分を書き換えるだけ** です。

| 項目 | 書く内容 |
|---|---|
| `sellerName` | 販売事業者名(個人なら氏名。屋号があれば屋号) |
| `representative` | 運営責任者の氏名 |
| `address` / `phone` | 住所・電話番号。個人の場合は「請求があった場合には遅滞なく開示いたします。」と書く方法もあります(条件があるので消費者庁の案内で確認してください) |
| `email` | 問い合わせ用メールアドレス(普段使いと分けるのがおすすめ) |
| `url` | 公開するサイトのURL |
| `effectiveDate` | ページを公開する日付 |

- 書き換えていない項目は、ページ上でピンク色に目立って表示されます。サーバー起動時にも警告が出ます。
- 文面はひな形です。本格的に売上が出る前に、一度専門家(行政書士・弁護士など)に確認してもらうと安心です。

**やってはいけないこと**
- 「的中率99%」など根拠のない宣伝(景品表示法に触れるおそれ)
- 利用者数やレビューの水増し・ねつ造
- 不安をあおって高額商品を買わせる売り方(霊感商法と見られるおそれ)
- 未成年に高額課金をさせる仕組み(月額の上限や保護者の同意を検討)

## 4. 税金

売上が出たら、個人事業主として開業届と確定申告が必要になる場合があります。金額が大きくなってきたら税理士や税務署に相談してください。
