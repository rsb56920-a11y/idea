🌙 夜華カナタ 配信セット

むりょう・かるい・Pythonなし。ダブルクリックとコピペだけで使えます

もくじ(上から順にやればOK。1〜4 だけで配信できます)
  1. フォルダを F ドライブに置く
  2. OBS にシーンを読みこむ
  3. OBS のパスワードを 設定.js に書く(口パク・表情に必要)
  4. 操作パネルを OBS に出す
  5. 文字や次回予告を変える
  6. フォロー通知を使う(やりたい時だけ)
  7. ボイスチェンジャー「コエカワ」を使う(やりたい時だけ)
  8. かるく配信する OBS 設定(VRAM 4GB 向け)
  9. こまったとき

このセットでできること

ファイルなにをするもの
soon / break / end .html「まもなく」「休憩」「おわり」の画面。星が流れて、月下美人の花びらが舞い、時計・次回予告・ちびカナタが動きます
pngtuber.htmlちびカナタ。マイクの声で口パク、自動でまばたき、パネルやキー 1〜4 で表情チェンジ。大声を出すと自動で「おこ」顔
mapcover.htmlLoL のミニマップをかくす、ちびカナタのパネル(こちらも口パク・まばたき)
alerts.htmlTwitch のコメントを吹き出しで表示。フォロー・サブスク・レイド・ビッツで演出と音
game-overlay.htmlゲーム中の名前プレートと時計
panel.htmlOBS の中に出す操作パネル(表情・シーン切りかえ・テスト)
コエカワ.html自分の声に合わせて自然に変えるボイスチェンジャー(無料・オフラインで動く)
設定.js名前・文字・パスワードなどを書くファイル。メモ帳で開いて書きかえるだけ
💡 ターミナル(黒い画面)は一度も使いません。Python もいりません。

1. フォルダを F ドライブに置く

  1. ダウンロードした 夜華カナタ_配信セット.zip を右クリック →すべて展開。
  2. 展開先を F:\ にして「展開」。
  3. エクスプローラーで F:\夜華カナタ_配信セット\ を開いて、中に soon.html や 設定.js があれば成功です。
⚠️ 場所と名前はこのままにしてください。F:\夜華カナタ_配信セット\夜華カナタ_配信セット\ のように二重になっていたら、中のフォルダを F:\ の直下に移動してください。
別の場所に置きたい時は、OBS に読みこんだあとで各ソースの「ローカルファイル」を選び直せば動きます。

2. OBS にシーンを読みこむ

  1. OBS を開いて、上のメニューの シーンコレクション → インポート。
  2. 右の「…」ボタンで F:\夜華カナタ_配信セット\OBS読みこみ用_夜華カナタ配信セット.json を選び、左のチェックを入れて インポート。
  3. メニューの シーンコレクション → 夜華カナタ配信セット をクリック。
  4. 左下の「シーン」に ① まもなく / ② ゲーム / ③ 休憩 / ④ おわり が出たら完了です。
✅ 星が動く画面が出ていれば成功!(まだ口パクはしません。次の3へ)
💡 ② ゲームの「LoLの画面」は、LoL の試合がはじまると自動で映ります。ロビー画面は映らないことがありますが正常です。

3. OBS のパスワードを 設定.js に書く

口パク・表情・通知の連動は、OBS の「WebSocket」という機能でつながります。

  1. OBS のメニュー ツール → WebSocket サーバー設定。
  2. WebSocket サーバーを有効にする にチェック。ポートは 4455 のまま。
  3. 接続情報を表示 → サーバーパスワード の横の「コピー」。
  4. F:\夜華カナタ_配信セット\設定.js を右クリック → プログラムから開く → メモ帳。
  5. obsPassword: "", の " " の中に貼りつけ(Ctrl+V)。例: obsPassword: "AbCd1234xyz",
  6. Ctrl+S で上書き保存。
  7. OBS のマイクの名前が「マイク」でないとき(音声ミキサーに出ている名前がちがうとき)は、micName: "マイク", もその名前に書きかえます。
  8. OBS を一度とじて、もう一度ひらきます。
✅ ② ゲームのシーンで声を出して、左のちびカナタの口が動けば成功!
💡 口が動きすぎる/動かない時は mouthThresholdDb: -38, の数字を変えます。-30 にすると反応しにくく、-45 にすると反応しやすくなります。
💡 パスワードがまちがっていると、ちびカナタの下に「OBSのパスワードがちがうよ」と出ます。

4. 操作パネルを OBS に出す

  1. OBS のメニュー ドック → カスタムブラウザドック。
  2. ドック名に カナタ、URL に file:///F:/夜華カナタ_配信セット/panel.html を貼って 適用。
  3. 出てきた小さな窓を、OBS の好きな場所へドラッグして置きます。

パネルでできること:

  • 表情: ふつう / おこ / しょんぼり / 目とじ(「5秒でもどす」にチェックで自動でもどります)。パネルをクリックしてからキー 1〜4 でも変わります。
  • シーン: ①〜④ をワンクリックで切りかえ。
  • テスト: コメント・フォロー・サブスク・レイドの演出を、配信前にためせます。
💡 OBS のブラウザソースは「ゲーム中に押したキー」を受け取れないしくみです。ゲーム中に表情を変えたい時は、OBS のホットキー(設定 → ホットキー)ではなく、パネルのボタンを使ってください。

5. 文字や次回予告を変える

設定.js をメモ帳で開いて、" " の中を書きかえて保存 → OBS でそのソースを右クリック → 更新(または OBS 再起動)。

書くところ変わるところ
soonTitle / breakTitle / endTitle各画面の大きな題名
gameTitle / endSub題名の下の小さな文字
startTime「まもなく」のカウントダウン。"21:00" のように書く。使わないなら ""
nextStream次回予告(例: "次回:金曜 21:00〜 LoL")
messages下で順番に流れるひとこと。行をふやしてもOK
showChat / alertSoundコメント表示・通知音のオン(true)/オフ(false)
⚠️ " や , を消してしまうと動かなくなります。うまく動かなくなったら、zip からもう一度 設定.js を取り出して書き直せば元にもどります。

6. フォロー通知を使う(やりたい時だけ)

コメント・サブスク・レイド・ビッツの通知は、設定なしですぐ使えます。フォロー通知だけは Twitch のきまりで「アプリ登録」がいります(無料・5分ほど)。

① Twitch にアプリを登録する

  1. https://dev.twitch.tv/console/apps を開いて Twitch でログイン(はじめての時は「2段階認証」の設定を求められます)。
  2. アプリケーションを登録。名前は kanata-overlay など何でもOK。
  3. OAuth のリダイレクト URL に http://localhost、カテゴリは Broadcaster Suite、クライアントの種類は 公開(Public)。
  4. 作成したアプリの 管理 を開き、クライアント ID をコピー。
  5. 設定.js の twitchClientId: "", の " " の中に貼って保存。

② 連携する(ふつうの方法)

  1. OBS を再起動すると、配信画面の真ん中に「コードを入れてね」という案内が出ます。
  2. スマホかパソコンで案内の URL を開き、表示されたコードを入れて 許可。
  3. 案内が消えたら完了。次からは自動でつながります。

③ ②がうまくいかない時の「かんたんな方法」

  1. 下の URL の ここにクライアントID を自分のクライアント ID に置きかえて、ブラウザで開きます。
    https://id.twitch.tv/oauth2/authorize?client_id=ここにクライアントID&redirect_uri=http://localhost&response_type=token&scope=moderator:read:followers
  2. 許可 を押すと「このサイトにアクセスできません」という画面になりますが、それで正しいです。
  3. そのときのアドレスバーの access_token= のうしろから & の前までをコピー。
  4. 設定.js の twitchToken: "", の " " の中に貼って保存 → OBS 再起動。
🔒 クライアント ID は人に見られても大丈夫ですが、トークン(twitchToken)は他の人に見せないでください。配信画面に 設定.js を映さないよう注意。トークンは2か月ほどで切れるので、その時は③をもう一度。
💡 配信前の確認は、パネルの「テスト」ボタンで演出を出せます。

7. ボイスチェンジャー「コエカワ」を使う(やりたい時だけ)

コエカワ.html をダブルクリックすると、ブラウザ(Edge か Chrome)で開きます。インターネットなしで動き、お金もかかりません。

  1. 開いたら あなたの声を測る(あなた専用の設定を作る) を押して、案内どおり少ししゃべります。自分の声の高さ・声のひびきに合わせて、自然になるよう自動で調整されます。
  2. なりたい声(女の子・美少年・イケボ など)を選んで ▶ 変換スタート。

OBS に変えた声をのせる

  1. 無料の VB-CABLE をインストール(パソコン再起動)。
  2. コエカワの 出力先 を CABLE Input にする。
  3. OBS の「マイク」ソースを右クリック → プロパティ → デバイスを CABLE Output に変更。
  4. 設定.js の micName は「マイク」のままでOK(口パクも変えた声で動きます)。
💡 Discord で使う時も、Discord の入力デバイスを CABLE Output にするだけです。
💡 声を変えない配信の日は、OBS のマイクのデバイスを元のマイクにもどしてください。
⚠️ 実在の人の声のまねを、本人の許可なく使うのはやめましょう。
🤖 もっと本物の女声に近づけたいときは、同じフォルダの AIボイチェン_無料で使う手順.html を見てね(無料・Pythonなし)。

8. かるく配信する OBS 設定(RTX 3050 Laptop / VRAM 4GB 向け)

このセットは 1秒30コマ以下・見えていない画面は自動で止まる ように作ってあるので、LoL と同時でも軽く動きます。OBS 側もこうしておくと安心です。

場所おすすめ
設定 → 映像 → 基本(キャンバス)解像度1920x1080
設定 → 映像 → 出力(スケーリング)解像度1280x720(余裕があれば 1600x900)
設定 → 映像 → FPS30(なめらかさ重視なら 60)
設定 → 出力 → 映像エンコーダNVIDIA NVENC H.264(CPU を使わない)
設定 → 出力 → ビットレート720p30 なら 3500〜4500 Kbps
設定 → 詳細設定 → プロセス優先度「通常より上」
OBS のアイコンを右クリック「管理者として実行」で起動すると、ゲーム中のカクつきが減ります
LoL 側フレームレート上限を 144 か 120 にしておく(無制限だと GPU が足りなくなりやすい)
💡 さらに軽くしたい時: ブラウザソースを右クリック → プロパティ → FPS を 30 → 20 に下げても見た目はほとんど変わりません。

9. こまったとき

こまりごとやること
画面が真っ黒/何も出ないフォルダの場所が F:\夜華カナタ_配信セット\ になっているか確認(1 を見てね)。
口パクしない① 設定.js のパスワード ② micName が OBS の音声ミキサーの名前と同じか ③ WebSocket が有効か。
「OBSのパスワードがちがうよ」と出るパスワードをもう一度コピーして貼り直し → 保存 → OBS 再起動。
コメントが出ない設定.js の twitchChannel が自分のチャンネル名(小文字)か確認。
通知の音が配信にのらない「通知とコメント」のプロパティで OBS を介して音声を制御 にチェック。
設定.js を変えたのに反映されないソースを右クリック → 更新、または OBS 再起動。
文字の形がちがうインターネットにつながっていない時は、パソコンの標準の字で表示されます(動作は問題なし)。
